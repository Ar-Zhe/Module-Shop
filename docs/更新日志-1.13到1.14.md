## 一、中文更新日志

### 1. 新增功能

1. **账单 / 收支明细**（点主界面顶部余额进入）：当前余额 + 今日收入/支出 + 本月收支汇总；「全部 / 支出 / 收入」筛选；明细按天分组（今天 / 昨天 / MM-dd），每行含类型、金额、备注、时间与**变动后余额**；整行滚动 + 滑块；停留时每 2 秒自动刷新。
   * 其它插件 / 模组可通过 **`/shop wallet log <玩家> <金额> [事由]`**（2 级权限，控制台可执行）或服务端 API `ShopManager.recordExternal(...)` 把外部账目写进玩家账单（类型显示「外部账目」，不动本模组余额）。
2. **侧栏菜单拖拽排序 + 模块增删**（管理员）：商店设置 →「编辑布局」→ 拖动页签换位。
   * 固定网格吸附（松手必定落在槽位）；拖动经过其它页签时实时让位、被挤开的页签用插值平滑滑动；
   * 存的是**顺序列表 + 已移除列表**而不是 X/Y 坐标，换分辨率 / GUI 缩放都不错位；保存即**热同步给所有在线玩家**；
   * **删除模块**：把页签拖到右侧工具条，卡片变红并显示垃圾桶图标，松手后二次确认才真正删除（**任何模块都能删**，只要求侧栏至少留一个）；
   * **加回模块**：下方模块管理里点「加入」，或把该行拖到左侧菜单（默认落在最下一格）；列表放不下时**左侧菜单与模块管理都可以滚轮下滑**，左侧最下面永远留一个空槽；
   * **编辑模式下模块功能全部停用**：内容区被毛玻璃盖住（连物品图标一起遮住），点哪里都不会跳转界面；工具条提供「完成 / 重置布局」。
3. **管理员指令：直接设置余额** `/shop admin money set <目标> <金额>`：把余额改成该值（`0` = 清零），在线/离线都可，记流水并立刻刷新在线玩家界面。
   * 与 `/shop admin money <金额> [目标]`（**加一笔**）区分开：一个加、一个改。
4. **兑换码系统重做**：
   * 生成器只保留「码」本身（兑换码 / 时效 / 每人限领 / 总上限 / 标题 / 公告），奖励改由一个「**配置奖励内容**」按钮进入；
   * 奖励配置界面与「管理员发放」同一套版式：3×9 真实物品槽 + 玩家勾选（搜索 / 翻页 / 全体玩家）+ 星币金额；保存后回到生成器并显示摘要，**可反复进去修改**；
   * 兑换码列表改成展开式卡片：**复制 / 编辑 / 查看 / 删除**。
     - 编辑：改时效 / 限领 / 总上限 / 标题 / 公告与奖励内容，**已领取的玩家不受影响**；
     - 查看：列出谁领了、各领了几次；
   * 自定义兑换码自动大写、过滤非法字符并**每 4 位自动补 `-`**（`AB12-CD34-EF56`）；随机码**去掉了固定前缀**。
5. **JEI 联动**：鼠标停在物品图标上按 **R**（这东西怎么来的）/ **U**（能用来做什么）直接打开 JEI 配方页。支持每日商店（翻开后）、每日收购、拍卖、玩家摊位、摊位商品页、邮箱附件、货币兑换、管理员列表；认玩家自己的按键绑定。**纯软依赖，服务器无需安装 JEI**。
6. **界面点击音效可换 + 当场试听**：提醒音效设置里新增一行，点一下切换并立刻试听，共 10 款（模组原音 / 木质轻点 / 原版按钮 / 石质清脆 / 机械咔哒 / 轻打点 / 清脆铃音 / 紫水晶 / 经验球 / 翻书页）；默认换成新的「点击」音。
7. **日程新增「错过即补发」开关**：定时发放的日程，玩家在时间点之后才登录时，当天内仍补发一次（与「补发离线玩家」相互独立）。
8. **收购全清奖励对管理员可见**：管理员界面直接显示当前生效的奖励金额。

### 2. 界面重做（本版重点）

1. **整套新 UI 设计系统**（写在一个 `IOStyle` 里，15 个界面无需改动即可吃到）：
   * **暗色扁平**：不透明近黑底（面板 `#0B0D13` / 左栏 `#080A0F` / 内容区 `#12151C` / 卡片 `#1A1E27`）；**直角不圆角**（`rounded()` 一律画方块）、**1px 硬边框**（常态 `BORDER` / 悬停 `BORDER_HOVER` / 禁用 `BORDER_DIM`）；强调色只留一个 `#2B4BFF`（绿/金/红/紫只做语义），选中项整条实心；
   * **取消发光 / 渐变 / 阴影 / 水波**：`gradient()` 退化成纯色、`topHighlight()` 空实现、`panel()` 去掉投影、按钮去掉外投影与悬停上浮 / 按下缩放、`drawRipple()` 空实现；`flashGlow()` 只把文字提亮一档（余额变化仍有提示）；
   * **字体**：面板 / 导航 / 按钮文字统一用**原版 Minecraft 像素字体、1.0 倍**绘制，内容区保留 0.8 倍小字；
   * 键盘焦点环与金额闪烁能力已备好，可继续扩展。
2. **底部操作条统一**：每个模块内容区底部固定 18px 底栏，刷新按钮 / 奖励提示 / 管理员开关 / 页码 / 操作提示全部排在这一条里，从右往左依次摆放。
   * 修掉了「当前 N / 总数」被「刷新商店」盖住、「全清奖励开关 / 设置按钮」压在「刷新收购」下面、「下面还有内容」箭头贴到面板边框等**所有底栏重叠**问题。
3. **翻牌动画重做**：改成**以左右中点为轴横向翻转**，前半段画背面、后半段画正面（在缩放趋近 0 的那一帧换面），配合 smoothstep 缓动 + 转向压暗 + 翻面扫光 + 轻微纵向透视压缩，时长 0.5 秒；方向由点击瞬间决定，不受网络延迟影响。卡牌与长条两种模式手感一致。
4. **邮箱界面重整**：列表与正文**字号缩小一号**（一屏从 6 封变 7 封）；正文按**中文逐字折行**（不再冲出面板）并可滚轮滚动 + 细滚动条；附件改为**格子**展示（最多 8 列 × 2 行，可滚轮整行滑动）。
5. **界面层级（返回规则）重做**：一级（商店主界面）/ 二级（签到、交易选择、摊位列表、账单、兑换码…）/ 三级（摊位商品页、数量输入、交易、日程编辑…）。
   * 返回 / ESC 一定跳到**不同**的上一级，不再来回循环；玩家关掉的界面**不会**被服务端快照复活；没有上一级时回一级界面，绝不把玩家丢回游戏。
6. **日程奖励改为「物品发放」式界面**：与管理员发放同一套容器（3×9 真实槽位 + 背包 + 金额），打开时**预填当前奖励**，取消时**只退还自己加进去的部分**（不丢不复制）。
7. **输入框全部“看得见”**：关掉原版自带的黑底/描边，统一画圆角底框，**聚焦时蓝色描边**；并修掉「先画控件、后画面板」导致输入框被整块盖住的根因。
8. **版式适配 GUI 缩放**：面板高度统一收紧（日程奖励设置 278→216、签到 276→246 等），标题与底部按钮不再跑出面板。

### 3. 体验优化与修复

1. **「全部领取」不再整批拦截**：金额先到账（不占背包），物品逐封尝试放入背包，装不下的**原样留在邮箱**并提示还缺几格。
2. **补签二次确认**（显示补签日期与花费），且补签后会**重算连续天数**，连续签到加成立即生效。
3. **邮箱改进**：同一来源 + 同类型 + 同标题且未领取的邮件自动**合并**（一封可带多件物品，同种物品自动叠组）；修复「配了 4 件物品，邮件里只显示 1 件」。
4. **每日商店刷新与每日收购刷新彻底分开**：各自独立次数、独立价格表（`dailyRefreshCosts` / `buybackRefreshCosts`）、独立流水与独立确认框。
5. **修复「余额一直显示（已满）」**：`maxBalance` 写 `0` 表示**不限**，之前会被配置范围纠正成 `1`，导致余额一超过 1 就提示已满、新钱进不来。现在 `0` 合法（=不限），并新增**启动日志打印生效上限**与悬停「余额上限 X」提示。
6. **修复「数量 / 金额输入界面点确认后回不去」**：确认后立刻返回上一级（原来只有交易金额会返回）；价格非法时也会红字提示，不再静默。
7. **修复领取按钮乱码**：货币类邮件的按钮漏加了语言键，直接把 key 画了出来；已补齐中英文，并全量校验了 272 个 `gui.module_shop.*` 键。
8. **移除「同一个 IP 只允许一个账号登录」限制**（删掉配置项、指令与存档字段）。**「同 IP 玩家之间不能转账」这条经济规则保留**。
9. **玩家摊位列表**从分页改为**整行滚动**（滚轮 + 蓝色滑块 + 「下面还有」小三角），并修复「摊位商品页 ↔ 列表」无限来回的返回循环。
10. **修复编辑日程 / 签到时被弹出界面**：只在玩家**没有任何界面**时才自动拉起商店主界面，其它情况只刷新缓存。
11. 其它：付费刷新加二次确认（写清花费与剩余次数）；「删除该日程」移到日程编辑页底部；物品选择器按发放界面样式重做（左格右列表、搜索缓存）；签到界面补「返回」按钮与里程点悬停说明；交易 / 转账返回改为真正回到上一级；每次翻牌动画时长与重复播放修正。

### 4. 升级说明

* **服务端**：只替换 `mods\module_shop-1.14.0.jar`。旧的默认配置会被自动迁移（邮箱上限 50→100、货币名 金币→星币、余额上限 999999999→9999999999），**只命中旧默认值时才改**，你自定义过的数值不动。
* **客户端**：装**同一个 jar**（服务端与客户端版本必须一致）。JEI 可选：装了就有 R/U 联动，没装行为不变。
* **配置文件**：如果你之前把 `wallet.maxBalance` 写成了 `0`（想表示不限），旧版会被纠正成 `1`；本版起 `0` 就是「不限」，若文件里已是 `1` 请手动改回 `0` 或任意大数字。
* **存档**：新增字段（邮件附件列表、日程奖励物品列表、侧栏顺序等）老存档自动取默认值，无需手动处理。
* **校验**：jar 的 SHA-256 见发布包内 `SHA256校验.txt`。

## Part 2 · English Changelog

### 1. New features

1. **Statement / transaction history** (click the balance in the top bar): balance, today's in/out, this month's in/out; All / Spent / Earned filters; entries grouped by day with type, amount, note, time and **balance after**; row-wise scrolling with a scrollbar; auto-refresh every 2 seconds.
   * Other plugins/mods can log external entries with **`/shop wallet log <player> <amount> [reason]`** (permission level 2, console-friendly) or the server API `ShopManager.recordExternal(...)`. They show up as "External entry" and never touch this mod's balance.
2. **Draggable sidebar menu** (admins): *Shop Settings → Edit layout*, then drag tabs to reorder.
   * Snaps to a fixed grid; other tabs move out of the way with smooth interpolation; a ≤3px movement is still a normal click (tab switching unchanged).
   * Stores an **order list**, not X/Y coordinates, so it survives resolution/GUI-scale changes; saved layouts are **hot-synced to every online player**.
   * While editing, the content area is dimmed and a centered Done / Reset toolbar is shown; clicks and wheel are swallowed to avoid mis-taps.
3. **New admin command** `/shop admin money set <target> <amount>`: sets a balance outright (`0` = clear); works for offline players, writes a history entry and refreshes the online player's UI immediately. Unlike `/shop admin money`, which **adds** coins.
4. **Redeem-code system reworked**:
   * The generator now only holds the code itself (code / expiry / per-player limit / total limit / title / announcement); rewards moved behind a single **Configure reward** button.
   * The reward screen reuses the exact layout of *Admin Grant*: 3×9 real item slots + player checklist (search / paging / select all) + coin amount. Save returns to the generator with a summary, and you can reopen it to edit any time.
   * The code list became expandable cards with **Copy / Edit / View / Delete**.
     - Edit: expiry, limits, title, announcement and rewards — **players who already claimed are unaffected**;
     - View: who claimed it and how many times.
   * Custom codes are upper-cased, stripped of invalid characters and **auto-dashed every 4 characters** (`AB12-CD34-EF56`); random codes **no longer carry a fixed prefix**.
5. **JEI integration**: hover an item icon and press **R** (how it is made) / **U** (what it is used for) to open the matching JEI page. Works in the daily shop (after flipping), buyback, auction, player stalls, stall item pages, mail attachments, currency exchange and the admin list. Uses your own JEI key bindings. **Soft dependency — the server does not need JEI.**
6. **Switchable UI click sound with instant preview**: a new row in the notification settings; 10 sounds (mod default, wooden tap, vanilla button, stone click, lever tick, soft tick, chime, amethyst, XP orb, page turn). The default is the new click sound.
7. **New per-schedule "catch up if missed" toggle**: schedules with a fixed time still grant once during the same day when a player logs in late (independent from "grant to offline players").
8. **Buyback completion bonus is visible to admins**: the admin screen shows the currently effective bonus amount.

### 2. UI overhaul (the headline of this release)

1. **A complete new design system** (all in one `IOStyle` class, so all 15 screens picked it up without changes):
   * Cool dark palette: near-black blue `#0F1218`; panels/cards now use a **vertical gradient + 1px inner highlight + cool-tinted shadow**; a single desaturated indigo accent `#6E8BFF` (green/gold/red/violet are semantic only); graded corner radii (panel 14 / card 10 / control 8 / chip 6).
   * Interaction: **hover** lifts 1px and lights the border; **press** scales to 0.97, drops the label and emits a **ripple** from the click point; **tabs** grow their selection block and stretch the accent bar; **cards** lift and get an edge spotlight; **balance changes flash blue**; every transition uses exponential approach so frame drops never snap.
   * Keyboard focus rings and amount-glow helpers are ready for future screens.
2. **Unified bottom action bar**: every module reserves an 18px bar at the bottom of the content area for refresh buttons, bonus hints, admin toggles, page numbers and hints, laid out right-to-left.
   * Fixed all bottom-bar overlaps (the "current N / total" counter hidden behind *Refresh shop*, the bonus toggle and settings button underneath *Refresh buyback*, and the "more below" chevron sitting on the panel border).
3. **Flip animation reworked**: cards/flips now rotate around the **left-right centre axis**, showing the back for the first half and the front for the second half (switching exactly when the scale approaches zero), with smoothstep easing, dimming while turning, a light sweep on reveal and slight vertical foreshortening, over 0.5s. Direction is decided at click time, so network latency cannot flip it back. Card mode and strip mode now feel identical.
4. **Mailbox layout reworked**: list and body text are one size smaller (7 mails per screen instead of 6); the body wraps **per CJK character** (never overflows the panel) and can be scrolled with the wheel plus a thin scrollbar; attachments became a **grid** (up to 8 columns × 2 rows, row-wise wheel scrolling).
5. **Screen hierarchy (back rules) reworked**: level 1 (the shop screen) / level 2 (check-in, trade select, stall list, statement, redeem codes…) / level 3 (stall item page, quantity input, trade, schedule editors…).
   * Back / ESC always moves to a **different** parent and never bounces in a loop; a screen the player closed is **not** re-opened by server snapshots; with no parent left it returns to level 1 instead of dropping the player into the world.
6. **Schedule rewards now use the "grant items" container**: same 3×9 real slots + player inventory + amount as *Admin Grant*; the current reward is pre-filled and cancelling only refunds what the admin added (nothing lost, nothing duplicated).
7. **All text fields are visible now**: the vanilla dark background/border is disabled in favour of a unified rounded field with a **blue border while focused**; the root cause (widgets drawn before the panel, so the panel covered them) is fixed.
8. **Layout now fits real GUI scales**: panel heights were tightened (schedule reward 278→216, check-in 276→246, …) so titles and bottom buttons no longer escape the panel.

### 3. Improvements & fixes

1. **"Claim all" no longer blocks the whole batch**: coins are credited first (they need no inventory space) and items are placed mail by mail; whatever does not fit **stays in the mailbox** with a message telling the player how many slots are missing.
2. **Make-up check-in asks for confirmation** (showing date and cost) and now **recomputes the streak**, so streak bonuses take effect immediately.
3. **Mailbox improvements**: unclaimed mails with the same source, type and title are **merged** (one mail can hold many items, identical items stack); fixed "4 items configured but only 1 shown in the mail".
4. **Daily shop refresh and buyback refresh are fully independent**: separate counters, separate price lists (`dailyRefreshCosts` / `buybackRefreshCosts`), separate history entries and separate confirmation dialogs.
5. **Fixed "balance always shows (full)"**: writing `0` for `maxBalance` means **unlimited**, but the config range used to correct it to `1`, so any balance above 1 showed "(full)" and new coins could not be credited at all. `0` is now legal, and the effective cap is printed to the server log at startup plus shown in the balance hover tooltip.
6. **Fixed "quantity/amount input does not close after confirming"**: confirming now returns to the parent screen (previously only the trade amount path returned); invalid prices also produce a red message instead of failing silently.
7. **Fixed the garbled claim button**: the money-mail button referenced a language key that was never added, so the raw key was drawn. Keys added in both languages and all 272 `gui.module_shop.*` keys verified.
8. **Removed the "one account per IP" login restriction** (config options, commands and save fields deleted). The economy rule **"players on the same IP cannot trade coins" is intentionally kept**.
9. **Player stall list** switched from pages to **row-wise scrolling** (wheel + blue scrollbar + "more below" chevron), and the infinite back-and-forth between a stall item page and the stall list is fixed.
10. **Fixed being kicked out of the schedule editor / check-in**: the shop screen is only opened automatically when the player has no screen open at all; otherwise snapshots just refresh the cache.
11. Misc: confirmation dialog for paid refreshes (cost and remaining uses); "Delete this schedule" moved to the bottom of the schedule editor; item picker rebuilt in the grant-screen style (grid on the left, list on the right, cached search); a Back button and milestone hover text in the check-in screen; trade/transfer Back now really returns one level up; flip animation duration and replay fixed.

### 4. Upgrade notes

* **Server**: just replace `mods\module_shop-1.14.0.jar`. Old default config values are migrated automatically (mailbox cap 50→100, currency name 金币→星币, balance cap 999999999→9999999999) — **only when the value still equals the old default**, so your customisations stay untouched.
* **Client**: install the **same jar** (server and client versions must match). JEI is optional: with it you get the R/U integration, without it nothing changes.
* **Config file**: if you previously set `wallet.maxBalance = 0` to mean "unlimited", older builds corrected it to `1`. From this version `0` means unlimited; if your file already says `1`, change it back to `0` (or any large number).
* **Saves**: new fields (mail attachment lists, schedule reward items, sidebar order, …) fall back to defaults for old saves; no manual action required.
* **Verification**: the jar's SHA-256 is in `SHA256校验.txt` inside the release package.
