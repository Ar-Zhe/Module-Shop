# 模块商店 · 模组介绍 / Module Shop · Overview

> **一句话**：给多人服务器用的**整合式经济商店** —— 每日商店 / 收购 / 拍卖 / 摊位 / 交易 / 邮箱 / 签到 / 兑换码 / 账单全在一套统一界面里，数值全部由服务端说了算。
> **In one line**: an **all-in-one economy shop** for multiplayer servers — daily shop, buyback, auction house, player stalls, player trading, mailbox, check-in, redeem codes and statements in one consistent UI, with every value owned by the server.

| 项目 | 内容 |
| --- | --- |
| 模组 id / Mod id | `module_shop` |
| 适配 / Target | Minecraft **1.21.1** · NeoForge **21.1.248**（Arclight 上实测可用 / verified on Arclight） |
| 安装 / Install | 服务端与客户端放**同一个 jar**；JEI 可选（不装也能玩）/ same jar on server and client; JEI optional |
| 语言 / Language | 简体中文 + English（自动跟随客户端语言 / follows the client locale） |
| 当前版本 / Version | **1.0.0** |

## 一、中文介绍

### 它是什么

一个**服务端权威**的模块商店：玩家在一个界面里买卖、拍卖、摆摊、交易、领邮件、签到、兑码；服主用指令或图形界面配置一切。所有价格、库存、奖励、余额都存在**世界存档**里，客户端只负责发操作请求，因此**改不了数值、刷不了钱**。

### 大体功能

**① 赚钱与花钱**

| 模块 | 大体说明 |
| --- | --- |
| 每日商店 | 每天一页**牌面朝下**的卡，点开才知道是什么；每件商品独立限购；花星币可**付费刷新**重抽整页 |
| 每日收购 | 每天随机几项收购需求，玩家把物品卖给服务器；**当天清单全部卖满有额外奖励** |
| 购物城 | 管理员上架的**常驻货架**（不会每日重抽）：两行六列、显示价格与库存、品质用颜色细边框表示；支持搜索、价格/库存排序、按模组分类、收藏与最近购买；管理员可单件上架或**一次导入整个模组** |
| 拍卖行 | 上架拍卖、出价即扣款、被超价自动全额退回、到期自动结算（成交走邮件、流拍原物退回） |
| 玩家摊位 | 玩家自己上架 / 改价 / 下架，别人逛摊购买；支持库存与售出统计、可配上架手续费 |
| 玩家交易 | 双方放入物品与星币 → 双方同意 → 倒计时 → 确认后**原子交换**；闲置自动结束并退回 |
| 货币兑换 | 管理员配置「1 个某模组货币 = N 星币」，玩家可双向兑换（物品 ↔ 星币） |
| 签到与日程 | 连续签到进度条 + 日历补签 + 管理员可配的**活动日/日程**（定时发放、补发离线、错过即补发、物品 + 星币奖励） |
| 兑换码 | 管理员生成兑换码（可设时效、限领、总上限、指定玩家、物品 + 星币奖励），玩家在邮箱输入兑换；支持复制、编辑、查看领取名单 |

**② 资产与账目**

| 模块 | 大体说明 |
| --- | --- |
| 钱包 | 余额查询、玩家间转账（冷却、余额上限饱和处理，不溢出也不变负） |
| 邮箱 | 物品邮件与金额邮件；一键领取、清理已读；背包满自动转邮箱；同来源邮件自动合并、附件用可滚动格子展示 |
| 账单 / 流水 | 点顶部余额进入：今日/本月收支、按天分组的明细、每笔的变动后余额；**其它插件的收支也能记进来**（外部账目） |
| 管理员发放 | 指令发星币（支持离线、全体、指定）与**直接设置余额**；也有图形发放界面（放物品 + 勾人 + 金额 → 邮箱领取）；配套交易流水查询 |

**③ 界面与体验**

* **统一暗色扁平风（参考 OneConfig 深色主题）**：直角面板 + **1px 硬边框**、不透明深色底，**没有发光 / 渐变 / 阴影 / 水波**；单一强调色 `#2B4BFF`，选中项整条实心；面板与导航用**原版 Minecraft 像素字体**，内容区保留 0.8 倍小字。
* 列表一律**整行滚动** + 右侧滑块 + 「下面还有」提示；底栏按钮统一排版，不会互相遮挡。
* **界面层级清晰**：返回 / ESC 一定回到上一级，不会来回循环，也不会把关掉的界面又弹回来。
* **侧栏菜单可拖拽排序、可增删模块**（管理员）：编辑布局里拖动页签换位，拖到工具条即**删除**（红色垃圾桶 + 二次确认），下方模块管理可「加入 / 移除」；顺序与「已移除」列表存在存档里并**热同步给所有在线玩家**；编辑模式下模块功能停用（点页签不切换界面），左侧菜单放不下可用滚轮翻。
* **JEI 联动**（可选）：鼠标停在物品图标上按 **R / U** 直接看它是怎么来的、能用来做什么。
* 界面点击音效可在设置里更换并**当场试听**（10 款）。

### 核心特点

1. **服务端权威**：所有数值在存档里，客户端只发操作包；拍卖出价、交易交换、发奖都在服务端校验并原子完成。
2. **升级只换 jar**：老存档新字段自动取默认值，旧默认配置自动迁移，不需要手动改配置文件。
3. **几乎一切可配**：价格表、刷新次数与费用、品质权重与保底、每日条目数、余额上限、签到档位与里程、日程、手续费、邮箱上限……都在配置文件或游戏内管理员界面。
4. **为多人服务器考虑**：离线玩家也能入账 / 收邮件、邮箱满自动兜底（转背包或掉落）、拍卖到期自动结算、同 IP 不能互相转账。

### 适合谁

* 生存服 / 经济服 / 整合包服：想要一套**开箱即用**的商店与经济闭环；
* 已经在用别的经济插件、想把「商店这一层」交给本模组的服主（外部账目可上报进账单）；
* 希望界面统一、不像一堆零散指令堆出来的服。

## Part 2 · English Overview

### What it is

A **server-authoritative** shop for multiplayer servers: players buy and sell, auction, run stalls, trade, collect mail, check in and redeem codes from a single UI, while admins configure everything through commands or in-game screens. Prices, stock, rewards and balances all live in the **world save**; the client only sends action requests, so values **cannot be edited or duplicated client-side**.

### At a glance

**① Earning and spending**

| Module | What it does |
| --- | --- |
| Daily shop | One page of **face-down cards** per day; flip to reveal; per-item purchase limits; pay Star Coins to **re-roll** the whole page |
| Daily buyback | A few random buy requests per day; sell items to the server; **a bonus when the whole list is completed** |
| Mall | A **permanent shelf** stocked by admins (no daily re-roll): 2×6 per page showing price and stock, quality shown as a 1px coloured border; search, price/stock sorting, filtering by mod, favourites and recent purchases; admins can add single items or **import a whole mod at once** |
| Auction house | List items, bids are charged immediately and refunded when outbid, automatic settlement on expiry (winner and seller are paid by mail, unsold items returned) |
| Player stalls | List / reprice / delist your own goods, browse and buy from others; stock and sold counters; optional listing fee |
| Player trading | Both sides put in items and coins → both agree → countdown → **atomic swap**; idle trades end and return everything |
| Currency exchange | Admins map "1 modded currency = N Star Coins"; players exchange both ways |
| Check-in & schedules | Streak progress, calendar make-up, and admin-defined **event days / schedules** (timed grant, offline grant, catch-up, item + coin rewards) |
| Redeem codes | Generate codes (expiry, per-player and total limits, player whitelist, item + coin rewards); players redeem them from the mailbox; copy, edit, and view who claimed |

**② Assets and records**

| Module | What it does |
| --- | --- |
| Wallet | Balance lookup and player-to-player transfers (cooldown, saturating balance cap, never negative) |
| Mailbox | Item and coin mails; claim all / clean read mail; overflow goes to the mailbox; mails from the same source merge; attachments shown as a scrollable grid |
| Statement / history | Click the balance for today's and this month's in/out, entries grouped by day with the balance after each one; **other plugins can log their own entries** |
| Admin grants | Command-based coin grants (offline, everyone, selected) and **setting a balance outright**; plus a graphical grant screen (items + players + amount → claimed from the mailbox) and per-player history |

**③ Interface and experience**

* **One consistent flat dark UI** (OneConfig-inspired): square corners with **1px hard borders** on an opaque dark base — **no glow, gradients, shadows or ripples**; a single accent colour (`#2B4BFF`) with solid-selected rows; panel chrome uses the **vanilla Minecraft pixel font** while content keeps its 0.8× small text.
* Lists scroll **row by row** with a scrollbar and a "more below" hint; bottom bars are laid out consistently and never overlap.
* **Clear screen hierarchy**: back / ESC always returns one level up — no loops and no reopening screens you closed.
* **Sidebar tabs can be reordered and modules added/removed** (admins): drag tabs to reorder, drop one on the toolbar to **delete** it (red trash panel + second confirmation), and use the module manager below to "add" / "remove"; order and the removed list live in the save and are **hot-synced to every online player**. While editing, module functions are disabled (clicking a tab does not switch screens), and the sidebar scrolls with the wheel when it overflows.
* **Optional JEI integration**: hover an item and press **R / U** to see how it is made or what it is used for.
* The UI click sound can be switched and previewed in the settings screen (10 sounds).

### Highlights

1. **Server-authoritative**: all values live in the save; bids, trades and grants are validated and completed atomically on the server.
2. **Upgrade by replacing the jar**: new save fields default automatically and old default config values are migrated — no manual config edits.
3. **Almost everything is configurable**: price lists, refresh counts and costs, rarity weights and guarantees, daily entry counts, balance cap, check-in tiers and milestones, schedules, fees, mailbox cap, and more.
4. **Built for multiplayer**: offline players still receive coins and mail, a full mailbox falls back to inventory or drops, auctions settle themselves, and players on the same IP cannot transfer coins to each other.

### Who it is for

* Survival / economy / modpack servers that want a complete shop-and-economy loop out of the box.
* Servers already running another economy plugin that want this mod to own the "shop layer" (external entries can be logged into the statement).
* Anyone who wants a coherent UI instead of a pile of raw commands.
