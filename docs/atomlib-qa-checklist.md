# AtomLib UI 迁移 · 游戏内 QA 清单（每日商店 / 签到 / 购物城 / 管理面板）

适用分支：`claude/1-21-1-module-store-ui-s7kpts`（NeoForge 1.21.1）与 `claude/1-20-1-module-store-ui-s7kpts`（Forge 1.20.1），两边页面代码一致，**两个版本各测一遍**。

环境：Windows x64 客户端（AtomLib 只带 Windows 原生库），同时安装 AtomLib 0.1.0-beta 对应版本的 jar；专用服务器**不装** AtomLib 也要能启动。
每一项都对照旧界面：按钮、点击效果、提示文字应与旧版一致，只是换成 Skija 绘制。

## 0. 通用
- [ ] 打开商店（K）各页切换无报错、无闪烁；切页后回来滚动位置保留
- [ ] 物品悬停显示原版 tooltip；悬停时按 R / U 能打开 JEI（装了 JEI 时）
- [ ] 中文、英文两种语言下文字不重叠、不出框
- [ ] 改 GUI 缩放（2 / 3 / 自动）与窗口大小后布局正常
- [ ] 专用服务器不装 AtomLib 能启动、玩家能进服

## 1. 每日商店（普通玩家）
- [ ] ≤6 件：2 行 × 3 列卡牌；背面按品质着色并显示品质名
- [ ] 点背面：翻牌动画（横向翻转、中途换面、压暗、扫光），物品图标跟着牌压缩，**中途不会突然冒出来**
- [ ] 翻牌后立即被服务端界面刷新时，动画继续播完，不会翻回去
- [ ] 点已翻开的牌：弹出购买数量输入（单价、剩余、余额正确）；买完剩余数量减少，卖完变红
- [ ] 已翻开的牌悬停显示物品 tooltip，背面不显示
- [ ] 刷新商店按钮：悬停显示花费 / 剩余次数；点击弹二次确认；次数用完时按钮为灰色样式
- [ ] >6 件（管理员把商品数调大）：变为长条列表，平滑滚动、滚动条可拖、底部渐隐；底栏显示「当前序号 / 总数」

## 2. 签到（普通玩家）
- [ ] 月历：今天蓝框、已签到绿色、未来灰色；年 << >>、月 < > 翻页正确
- [ ] 补签期内的过去日期：悬停提示补签费用；点击弹确认并补签成功；超出补签期的日期不可点
- [ ] 有日程的日期：底部彩色短线（最多 3 条），悬停显示标题 / 正文 / 星币 / 物品
- [ ] 进度条（开了累计加成或里程奖励时）：圆点到达变绿，悬停看奖励，右侧「第 N 轮」
- [ ] 今日签到按钮：悬停显示可得星币；签到后变为「已签到」且不可再点；状态文字更新

## 3. 购物城（普通玩家）
- [ ] 搜索框：可输入中文（输入法候选窗在输入框下方）、实时过滤；输入时数字键不切页
- [ ] 「搜索」按钮让输入框失焦；点侧栏 / 切页时输入框失焦
- [ ] 「只看收藏」开关；卡片右上角星标点击收藏 / 取消，点星标不会触发购买
- [ ] 排序下拉 5 项、分类下拉（按模组，可滚轮滚动）：点选项应用并收起；点别处只收起、**不会顺手买到卡片**；下拉展开时物品图标不穿透下拉
- [ ] 卡片：品质 1px 细边框、价格、库存（无限 / 售罄 / 剩余）；左键买（弹数量）、右键批量买；售罄不可买
- [ ] 滚轮 / 底栏按钮翻页；底栏状态（个人库存、定时补货提示）正确
- [ ] 「最近购买」：列表平滑滚动，返回货架按钮可用；空列表提示

## 4. 管理面板（管理员，/shop admin）
- [ ] 「选择模块编辑」下拉：7 个模块，点选切换；当前模块有标记；展开时列表物品图标不穿透
- [ ] 顶部「发放物品」「交易记录」可用
- [ ] 每日商店 / 收购 / 购物城 / 出货箱：一页 5 条，左键编辑、右键删除；翻页与滚轮翻页；数量列含义正确（库存 / 每日份数 / 上限）
- [ ] 出货箱写一条格式错误的规则：整行标红显示原文，左右键都能删除
- [ ] 各模块底部按钮：添加条目 / 刷新参数 / 导入模组 / 补货设置 / 刷新模式 / 每日额度 / 下架时间 / 求购设置，选中态与旧版一致
- [ ] 摊位：显示下架时间说明；求购：摘要 + 全部求购，点一行弹强制撤销确认
- [ ] 签到：月历；点「编辑日程」后点日期新建 / 修改日程，右键右上角小方块清空当天；底栏显示设置摘要 / 编辑态提示
- [ ] 底栏第二行：页码、收购全清奖励金额、操作提示不重叠

## 5. 回退
- [ ] 装了 AtomLib 但 Skija 原生库加载失败（如 Linux / macOS 客户端）时：商店仍可打开，这 4 页自动退回旧界面且功能正常（客户端不装 AtomLib 会因 mods.toml 依赖声明无法启动，这是预期行为）
