# 模块商店 · 使用教程

> 适用版本：`module_shop-1.0.0.jar`（Minecraft 1.21.1 / NeoForge 21.1.x，已在 Arclight 1.21.1 混合端实测）
> 本文按「玩家篇 → 管理员篇 → 配置 → 常见问题」的顺序写，第一次用建议先看**一、安装与准备**和**三、管理员篇**。

---

## 一、安装与准备

| 步骤 | 说明 |
| --- | --- |
| 1. 服务端 | 把 `module_shop-1.0.0.jar` 放进服务端 `mods/`，重启 |
| 2. 客户端 | **玩家也必须安装同一个 jar**（商店界面是客户端代码，不装看不到界面） |
| 3. 打开界面 | 游戏里按 **K**，或输入 **`/shop`** |
| 4. 管理员 | 输入 `/shop admin`，或在商店界面**右上角**点「**商店设置**」药丸（仅管理员可见） |

> 服务端**只需要替换这一个 jar**：所有玩法配置都存在世界存档里，配置文件的旧默认值会自动迁移，不用手动改。
> 配置文件必须是**不带 BOM 的 UTF-8**（带 BOM 时 NeoForge 会报 `Invalid bare key` 并把配置重置）。
>
> ⚠ **服务端与客户端必须换成同一个 jar**（通信通道版本已提到 2）。
> 只更新一边时进服会提示通道版本不一致 —— 这是刻意做的提示：
> 旧客户端遇到新服务端的数据格式会直接崩成「Network Protocol Error」，
> 所以宁可给一句看得懂的话，也不要用一个解码崩溃把人踢下线。

## 二、玩家篇

### 1. 主界面导览

```
┌ 头像 玩家名                     [签到] [交易] [转账] ┐
│      余额：646554星币  ← 点这里看「账单」            │
├──────────┬──────────────────────────────────────────┤
│ 每日商店 │                                          │
│ 购物城   │              当前页签内容                 │
│ 每日收购 │                                          │
│ 出货箱   │                                          │
│ 拍卖会   │                                          │
│ 玩家摊位 │                                          │
│ 邮箱     │                                          │
│ 货币兑换 │                                          │
├──────────┴──────────────────────────────────────────┤
│ ⚙商店设置（管理员）                                  │
└─────────────────────────────────────────────────────┘
```

* 左侧是页签：**每日商店 / 购物城 / 每日收购 / 出货箱 / 拍卖会 / 玩家摊位 / 邮箱 / 货币兑换**（切页签不算换界面）。
  左侧模块区**一屏固定显示 6 个**，第 7 个起鼠标放在左侧列表上**滚轮上下滑**即可 ——
  右侧会出现一条蓝色细滑块，列表下方写着「滚轮查看其余 N 个模块」；管理员还能在「编辑布局」里拖动排序、删掉不需要的模块。
* 顶部：**签到**、**交易**、**转账**；有未读事项时按钮上会出现红点数字。
* 顶部左侧的**余额**可以点 —— 打开**账单**（详见下面第 13 节）。
* 左下角小齿轮 = 提醒音效设置（含**界面点击音效**，10 种可试听）。

### 2. 每日商店

* 每天自动生成 6 张（可配）**牌面朝下**的卡，点一下**翻牌**（翻开才知道是什么；牌背颜色代表品质）。
  翻牌是**以卡牌左右中点为轴的真实翻转**（转过去时压暗、翻面后扫过一道光），0.5 秒左右完成。
* 翻开后再点该卡 = **购买**，会弹出数量窗口（可一次买多件）；每件物品有**自己的每日限购**，卡面右下显示「剩余 N」。
* 牌数超过 6 时自动变成**长条模式**（一行一个），右边显示 `当前 / 总数`，**滚轮整行滚动**、右侧有滑块；
  长条翻牌同样是**以左右中点为轴翻转**（横向翻转 + 轻微纵向收窄 + 压暗 + 扫光），和卡牌手感一致。
* 右下角「**刷新商店**」= 付费重抽整页卡牌：会先弹确认框写清**花费**与**今日剩余次数**；价格表与次数在配置里（`dailyRefreshCosts`），**与收购刷新完全独立**。
* 买到的物品直接进背包；**背包满自动转邮箱**（不会丢）。

### 3. 购物城（常驻货架）

和「每日商店」不同，购物城是**管理员上架的常驻货架**：不会每天重抽，价格与库存都由管理员定。

* **两行六列**一页 12 件：物品图标 + 名称 + **价格** + **库存**；**品质只用 1px 颜色细边框表示**（金=传说 / 紫=史诗 / 蓝=稀有 / 绿=普通），不写品质文字。
* **搜索**：左上角输入框直接打字（可按**物品名**或**模组名**过滤），右边「搜索」按钮只是收起焦点。
* **排序**：第二行左边「排序」下拉 —— 默认 / **价格升序 / 价格降序 / 库存升序 / 库存降序**。
* **按模组分类**：中间「分类」下拉列出货架上所有模组（**按名称首字母排序**，可滚轮下滑），点一项只看该模组的物品。
* **只看收藏**：点卡片**右上角的小星星**收藏（★），再点「☆ 只看收藏」就只显示收藏过的物品。收藏是**本地保存**（`config/module_shop_mall_favorites.txt`），换存档也在。
* **最近购买**：右下角按钮切到购买记录列表 —— **最新的在最上面**，每行是「物品 ×数量 / 玩家 / 总价 / 时间」，滚轮往下翻。
* **翻页**：底栏显示「第 x / y 页 · 共 N 件」，左右按钮或**鼠标滚轮**翻页。
* **购买**：点卡片（不点星）弹数量窗口，会显示单价、总价与购买后余额；库存不够时按剩余数量成交，**卖完显示「已售罄」**（卡片变灰、不能再买）。
* 买到的物品直接进背包，**背包满自动转邮箱**。
* **定时补货（可选）**：管理员可以在「商店设置 → 购物城 → 补货设置」里打开 —— 到点把**卖掉的库存补回去**
  （每件补回各自原量，或统一补到某个数量；**无限库存 ∞ 的商品不参与**）。
  补货时刻按**现实时间**或**游戏时间**算都行；打开后玩家在底栏能看到「**每日补货 00:00（现实时间）**」，
  售罄只是暂时的；补货时会给全服发一条绿字提示。

### 4. 出货箱（参考星露谷售货箱）

把不用的东西丢进去，**第二天早上 6:00** 自动换成星币到账 —— 不用摆摊、不用等人买。

* **每人一个独立空间**（和末影箱一样，别人看不到也拿不到）：点「**打开出货箱**」把自己的东西放进去；
* **只能放「兑换规则」里写了的东西**：不在规则里的物品**放不进去**（拖、点、Shift 快速移动都会被拒绝），
  聊天栏会提示「这个物品不在兑换规则里」。规则由管理员在配置文件里设置（见管理员篇第 13 节）；
* **结算时间**：每天**早上 6:00**（游戏时间）结算一次，你放进去的东西会在**第二天早上 6:00** 卖掉 ——
  界面顶部写着「距下次结算 X 时 Y 分」；结算后钱直接进余额，并写一条账单流水（类型「出售 / 出货箱」）；
* **本次结算金额实时显示**：界面顶部一直写着「**本次结算：X 星币 · 箱内 N 件**」，
  你往里放东西时数字会**当场跟着变**；同一区域还会显示「今日已结算 Y / 上限 Z」；
* **每日上限**：每天能结算的**金额**有上限（按等级配置，**现实时间 0 点刷新**）。
  箱里的东西如果超过今日剩余额度，会**只卖到额度用完为止**，**剩下的留在箱子里**第二天继续结算
  （不会白白损失），并提示「今日结算额度已用完」；
* **升级**：主界面点「**升级（X 星币）**」提升容量：**9 → 18 → 27 格**（三级，最高 27 格）；
  升级花费、每级容量、每日上限、结算时间都在配置里（管理员篇第 13 节）；
* **右侧「可卖物品」清单**：打开出货箱后，右边会把**兑换规则覆盖到的物品**全列出来（★ 标记 / 物品图标 / 名称 / 单价），
  开关都在**清单上方**：搜索框、分类、排序、只看已有、只看标记 —— **打开「只看已有」会把你背包里能卖的物品亮绿框**，
  **打开「只看标记」会把标记过的物品亮金框**，一眼就知道该放什么。原来的说明：
  还能：**搜索**名字 / **按模组分类** / **按价格或名称排序** / 点行首 ★ **标记**物品（可「只看标记」）/
  **只看已有**（只显示你背包里真的有的）；**左键点一行 = 把背包里那一叠直接放进去**，
  鼠标悬停能看到单价、每天最多结算几个、你现在有几个 —— 一眼就知道什么能卖、值多少钱。
* **规则写错了会提醒**：界面红字显示「兑换规则有 N 处格式错误」，底部还会写出第一条错误的具体行号与原因。

### 5. 每日收购

* 每天随机若干收购项：物品图标、品质、收购单价、还能收购多少。
* 点某一行 → 弹数量窗口（会提示该物品今日还能卖多少、你背包里有多少）→ 确认出售。
* 底部显示「**收购全清奖励**」进度：今天把清单全部卖满，可额外拿一笔奖励（每天一次）。
* 右下角「**刷新收购**」= 付费重抽今日收购清单（与商店刷新各自独立计费与计数，同样有二次确认）。

### 6. 拍卖会

* **上架**：选择物品 → 设起拍价与数量 → 上架（每名玩家同时进行的拍卖数量有限制）。
* **出价**：点条目进入出价界面，可 `±5 / ±10` 快捷调价；被超过的价格会**划掉显示**。
* 成交后卖家所得会扣**手续费**（配置百分比）；开启防狙击时，临近结束出价会自动延时。
* 到期未售出 / 被超价退款：物品与星币都会退回，**背包放不下的进邮箱**。
* 每件商品旁显示**累计已售出件数**。

### 7. 玩家摊位

* **上架物品**：管理自己的摊位（上架时填单件价格与库存数量，库存最多 64 且不能超过你实际持有量）。
* **逛摊位**：点「逛摊位」→ 玩家摊位列表（带**头像**、商品件数）→ 点某个玩家进入其摊位 → 点商品弹出数量窗口购买。
* 列表支持**滚轮整行滚动 + 右侧滑块 + 底部「下面还有」小三角**。
* 商品卖空会显示「已售空」，摊主会收到一封**售空提示**邮件。

### 8. 玩家交易

1. 顶部「交易」→ 在线玩家列表（可搜索）→ 点玩家发出交易请求。
2. 对方聊天栏/交易界面里同意后，双方进入交易界面。
3. 每方最多放 **6 件物品**，可设置**星币**金额（放物品与设金额分别在容器界面和输入界面完成）。
4. 双方都点确认 → 3 秒倒计时 → 交换完成。
5. 超时（默认 10 分钟）自动结束，物品与星币**原路退回**（放不下进邮箱）。

### 9. 钱包与转账

* 顶部「转账」→ 在线玩家列表（搜索）→ 选人 → 输入金额 → 确认。
* 规则：有**冷却时间**、**余额上限**（不会溢出也不会变负）、**同一个 IP 的玩家之间不能转账**（防小号刷钱；管理员不受限）。
* 收到的转账会在聊天栏提示。

### 10. 邮箱

* 左侧邮件列表（含状态点、星标、发件人），右侧详情（标题 / 发件人 / 时间 / 正文 / 附件）。
* 物品邮件点「**领取**」，金额邮件点「**领取**」（金额类只需查看即到账）。
* 底部「**全部领取**」：金额先到账，物品逐封尝试放入背包，**放不下的整封留在邮箱**并提示还缺几格。
* 「删除已读」一键清理已读/已领邮件；未领取的邮件删除前会**二次确认**。
* **星标**：点右上角星号置顶显示（星标邮件不会被自动清理）。
* **附件区是格子**：一排最多 8 列 × 2 行，鼠标放格子上滚轮可上下滑动看更多；图标上悬停看完整信息。
* **容量 100 封**（可配）：满了以后收到新邮件时，会自动删除**最早的一封已读邮件**并提示；删不出来时物品转背包/掉落、金额直接到账。
* **同渠道邮件自动合并**：来源 + 标题 + 正文相同且还没领取的邮件会**并成一封**（同种物品自动叠组），不会一封信只装一件东西。
* 有效期：日程「物品发放」与管理员发放的物品邮件保留 **30 天**，其它邮件默认永久；列表里会显示「N 天后自动删除」。

### 11. 货币兑换

* 管理员配置好「1 个某模组货币 = N 星币」的汇率后，玩家在长方形列表里**点击展开**某条目：
  * 「**兑换**」：物品 → 星币（会显示你背包里有多少、最多能换多少）；
  * 「**取款**」：星币 → 物品（背包放不下自动进邮箱）。
* 支持滚轮浏览，全部计入账单/流水。

### 12. 签到与日程

* 上方是**连续签到进度条**：里程点会按连续天数点亮，鼠标移到里程点上显示「**连续签到加成：X星币**」。
* 中间「完成签到」按钮：每天一次，奖励 = 每日基础 + 当前**累计加成**；达到里程点额外发一笔里程奖励。
* 日历：**补签**（点过去的日期，会显示花费与日期的二次确认）、今日高亮、已签到变绿。
* **日程（活动日）**：日期格底部有颜色小条，鼠标悬停显示日程详情（标题 / 正文 / 金额（金色小字）/ **奖励物品图标**，图标上可看名字）。
* 右下角「**返回**」，管理员另有「累计签到加成 / 登录自动签到 / 连续签到设置 / **启动编辑**」四个按钮。

### 13. 账单（支付软件式收支明细）

**入口：点主界面左上角的余额。**

* 顶部汇总：**当前余额** + 今日收入 / 今日支出 + 本月支出 · 收入。
* 筛选页签：**全部 / 支出 / 收入**。
* 明细**按天分组**（今天 / 昨天 / MM-dd），每天一行小标题显示当天「支出 · 收入」合计。
* 每行：类型名 + 金额（收入绿色 `+`、支出红色），第二行是备注与对方，右侧是**时间**与**变动后余额**。
* 滚轮**整行**滚动 + 右侧蓝色滑块 + 底部「下面还有」提示；界面停留时**每 2 秒自动刷新**，右下角也有「刷新」按钮。
* 记录范围：购买 / 出售 / 摊位买入卖出 / 拍卖出价退款成交 / 转账 / 玩家交易 / 邮箱领取 / 管理员发放 / 签到 / 补签 / 刷新商店 / 刷新收购 / 收购全清奖励 / 货币兑换取款 / 兑换码，以及**外部账目**（见管理员篇第 9 节）。

### 14. 兑换码

邮箱右上角「**兑换码**」→ 输入码（自动转大写）→ Enter 提交；成功会展示奖励并进邮箱，失败会红字抖动提示。

## 三、管理员篇

### 1. 进入管理界面

`/shop admin`（2 级权限），或在商店界面**右上角**点「**商店设置**」药丸（这一枚只对管理员显示，在最左边）。

### 2. 配置商品池

* 用**幽灵槽**放入物品（不会真的从你背包扣走），然后填**价值 / 品质 / 库存(数量)**，保存即生效（在线玩家会立刻同步）。
* **品质不再是文本框**：改成一排**品质按钮**（传说 / 史诗 / 稀有 / 普通），点一下即选中，
  按钮上方写着「品质　**当前品质：X**」并跟着变色 —— 不用再手打 `legendary/epic/rare/common`，也不会打错字。
* 上方用「**选择模块编辑**」下拉切换编辑对象：点一下按钮展开列表（**每日商店 / 每日收购 / 购物城**，当前正在编辑的那一项带勾），
  点其中一项即切到该模块的编辑界面；右侧一直显示「当前编辑：XXX」。切换后会同步给服务端，之后放入的物品就归属该清单。
  > 这个下拉是**通用入口**：以后模组新增可按模块配置的功能，会直接出现在这个列表里。
* **数量 / 库存的语义按模块不同**：每日商店 / 收购是「每天的上限」（留空用默认）；
  **购物城是库存**（留空或 `-1` = **无限**、`0` = **售罄**、正数 = 剩余件数）。
* **打开「购物城」时**，底部第一行的「刷新参数」会换成「**导入模组**」（购物城常驻、没有每日刷新参数）。
* 修改后可用 `/shop admin reload` 让所有在线玩家立即同步。
* **如果保存时提示「价格无效」**：先确认价格填的是**大于 0 的整数**；
  若填对了仍被拒，多半是**余额上限**太小（提示里会写出上限值）。配置文件里 `maxBalance = 0` 表示不限；
  早期版本曾把 0 误纠正成 1，导致上限变成 1 星币、任何商品都存不下来 —— 现在代码会把 `<= 1` 一律当作「不限」，
  启动时也会把配置文件里的 `maxBalance = 1` 自动改回 `0`，无需手动处理。

### 2.1 上架购物城商品（单件 / 整模组）

* **单件**：把「选择模块编辑」切到**购物城** → 点底部「**添加物品**」→ 幽灵槽放入物品 → 填价格 / 品质 / 库存 → 保存；
  也可以直接点左侧「**添加物品**」按钮（会自动把编辑对象切成购物城）。保存后自动回到购物城页，能立刻看到新上架的那件。
* **整个模组一次性导入**：底部点「**导入模组**」→ 打开导入界面：
  1. 点上方「**选择模组分类 ▼**」展开 / 收起模组列表（**按名称首字母排序**，可滚轮下滑，右侧显示「当前区间 / 总数」）；
  2. 点一个模组选中它；
  3. 点底下「**添加模组 +**」；
  4. 在弹出的窗口里填**统一价格 / 统一库存**、点**品质按钮**选统一品质，保存 —— 该模组的**全部物品**一次性上架。
* 导入界面底部有一项「**跳过没有名字的技术物品（推荐）**」（默认开）：模组内部用来做图标 / 属性的隐藏物品没有翻译，
  名字会显示成 `item.xxx` 这种乱码，勾上就不导入它们（悬停有说明，取消勾选则原样全导入）。
* **重复导入不会重复上架**：已经在货架上的物品会按注册名跳过（聊天栏会提示「新增 N 件 / 已存在跳过 M 件 / 无名字跳过 K 件」）；
  单次最多导入 2000 件，超出的再导入一次即可。
* 想改价 / 改库存 / 下架：回到「商店设置」页、模块选**购物城**，**左键点某一行**改价值 / 品质 / 库存，**右键删除**。
* 玩家购买后库存自动扣减；**库存 0 显示「已售罄」**（卡片变灰但仍留在货架上，方便你补货）。
* **补货设置**（模块选**购物城**时底部第三个按钮）：弹窗 4 项 —— **定时补货 关/开**、**时间口径（现实时间 / 游戏时间）**、
  **补货时刻**（HH:mm，只填数字会自动补冒号，格式不对红字提示并拒绝保存）、**补货数量**
  （`0` = 每件补回**各自原量**，即你上架/导入时填的那个数；`>0` = 所有商品**统一补到该数量**）。
  保存后立刻写回配置文件（`[mall]` 段：`mallRestockEnabled` / `mallRestockMode` / `mallRestockTime` / `mallRestockAmount`）；
  每个补货日只补一次，服务器重启也不会重复补；想「限量但不自动补货」的商品，把它的库存设成 **∞**（无限）即可。
  按钮在**开启状态会高亮**，一眼能看出补货有没有生效。

### 3. 刷新参数（每个模块独立）

管理界面里的「**刷新参数**」按**当前模块**（商店 / 收购）分别设置：

* **品质权重**：传说,史诗,稀有,普通（决定抽卡概率）；
* **保底数量**：稀有,史诗,传说（保底不足时优先替换普通项）；
* **条目 / 牌数上限**：每天生成的条目数量（超过 6 自动进长条模式）。

### 4. 发钱 / 发物品

```
/shop admin money <金额>                 给所有已知玩家（在线 + 历史离线）各发这么多
/shop admin money <金额> <目标...>        只发给指定玩家：玩家名（离线也行）/ UUID / all / @a
/shop admin money set <目标> <金额>        ★把余额**直接设为**该值：set <玩家名> 0 = 把他清零
/shop admin send                        打开发放界面：放入物品 + 勾选玩家或全体 + 可选金额 → 发送（物品进邮箱）
/shop wallet give <在线玩家> <金额>       只给一个在线玩家
```

> 单次金额不能超过 `maxBalance`（超出直接拒绝）；余额到顶的部分不会发放；每一笔都写进账单与流水。
> **`money` 是「加一笔」，`money set` 是「改成这个数」**：想清空 / 收回误发的钱用 `money set <玩家> 0`，
> 想要自己清零就写自己的名字（`/shop admin money set 你的ID 0`）；目标离线也能改，玩家下次上线即是新余额。

  * 再点「日程奖励」按钮打开**物品发放式界面**：左侧 3×9 真实物品槽（把要发的物品放进去，打开时会预填当前奖励）、右侧显示当前奖励与金额、底部「保存 / 取消」；

### 7. 兑换码生成器

邮箱右上角「**兑换码**」→「兑换码生成器」（仅管理员）。这一页只管「码」本身：

* 🎲 随机码（不含固定前缀）；也可以手输自定义码 —— **每 4 位会自动补一个 `-`**（如 `AB12-CD34-EF56`），自动大写、自动过滤非法字符；
* 时效 7 天 / 30 天 / 永久；每人限领、总上限；标题、公告正文（每个输入框都有明确的输入区域）；
* **奖励内容不在这页填**：点「**配置奖励内容**」进入奖励配置界面 —— 与「管理员发放」同一套版式：
  左侧 3×9 真实物品槽（从背包拖入）+ 星币金额，右侧是玩家名单（可搜索 / 翻页，下面有「**全选**」「**全不选**」）；
* **兑换范围（重要）**：**一个玩家都不勾 = 全体玩家都能兑换**（默认）；
  只要勾了人，这个兑换码就**只有被勾选的那些玩家能兑换**（别人输入会提示不可兑换）。
  左侧会随勾选状态显示「未选玩家 · 全体玩家均可兑换」或「已选 N / M 名玩家」；想改回全体，点「全不选」或把勾都取消再保存即可；
  点「**保存**」回到生成器，上面的摘要会显示「物品 / 星币 / 玩家（全体玩家 或 N 名）」，**随时可以再点进去修改**（草稿会预填回槽位与勾选）；
* 奖励以邮件形式发放（邮箱满时自动转背包/掉落）；生成成功后兑换码自动复制到剪贴板；
* 点「列表」看已生成的兑换码（展开式卡片，和货币兑换列表同款）：
  * **复制**：把码写进系统剪贴板（也可 Ctrl+C）；
  * **编辑**：改时效 / 限领 / 总上限 / 标题 / 公告与奖励内容，**已经领取过的玩家不受影响**（不会补发、也不会重置领取记录）；
  * **查看**：列出谁领了、各领了几次；
  * **删除**：删除该兑换码。

### 9. 侧栏菜单排序（拖拽换位 · 增删模块）

1. 进入「商店设置」页 → 第一行最右点「**编辑布局**」；
2. 进入编辑模式后，右侧内容区会被一整套**毛玻璃面板**盖住（连物品图标与文字一起遮住，不会再有「上一级界面漏出来」），顶部是「**完成 / 重置布局**」工具条；
3. **按住左侧任意页签拖动**即可调整顺序（行为等同手机整理 APP 图标）：
   * 菜单固定在**网格槽位**里，松手后按钮**自动吸附到最近槽位**，不会出现像素级偏移或重叠；
   * 拖动经过其他页签时，**其余页签会平滑地前后移动让出空位**（插值动画，不是瞬移）；
   * 被拖拽的页签跟随鼠标并放大高亮，**绘制在最上层**；
4. **编辑模式下模块功能全部停用**：点右侧内容区、点页签都**不会切换界面**，只有工具条、左侧槽位与下方模块管理会响应（想切页先点「完成」退出编辑）；
5. **删除模块**：把某个页签拖到右侧工具条的卡片上 —— 卡片会变成**红色半透明面板**，中间出现**垃圾桶图标**并提示「删除该模块 / 松手即删除（会再确认一次）」；
   松手后弹出**二次确认**（「确定删除「XX」？」+「删除后可以随时在下方模块管理里加回来」），点「**删除**」才真正移除，点「取消」什么都不做；
6. **模块管理（下方列表）**：一屏列出**所有模块**——已启用的在上（右侧是红色「**移除**」），未启用的在下（右侧是强调色「**加入**」）；
   **模块多于一屏时，鼠标停在这张列表上滚轮即可往下翻**（右侧有滚动条，右上角显示「当前区间 / 总数」，例如 `1-6/7`）；
   加回左侧有**两种方式**：
   * 点该行右侧的「**加入**」按钮（按下选中时会高亮）；
   * 或者**按住该行直接拖到左侧菜单**——拖动时左侧会出现一个**预留空槽**（画着「新模块位置」），松手即按最近槽位插入，**默认落在最下一格**；
   > 侧栏**至少保留一个模块**（否则侧栏空了就没有入口再加回来）：只剩一个模块时它的「移除」会置灰，列表上方也会红字说明。
7. **左侧菜单同样支持滚轮**：一屏只显示 **6 个模块**，鼠标放在左侧菜单列上滚动即可上下翻页（右侧有蓝色细滑块、下方有「滚轮查看其余 N 个模块」），
   列表**最下面永远保留一个空槽**（滚到底才看得见），防止把所有模块都拖上去之后无处可放；
8. 松手即保存：存的是**顺序列表 + 已移除列表**（不是坐标），保存在**服务端存档**里，并**立刻热同步给所有在线玩家**
   （别人下次打开界面就是新顺序，不用重启、不用改配置；换分辨率 / 换 GUI 缩放也不会错位）。
   记「已移除」而不只是从顺序里删掉，是为了**以后版本新增的模块依然会自动出现**，只有你显式删过的才不显示；
9. 想恢复默认：点工具条里的「**重置布局**」；点「完成」退出编辑模式。

> **左侧菜单列的滚轮在两种模式下都生效**（模块超过 6 个时）；**右侧内容区**的滚轮只在非编辑模式生效，
> 编辑模式下内容区的滚轮会翻**下方模块管理**列表（各翻各的，互不干扰）。

### 10. 外部账目上报（其它插件扣的钱也进账单）

别的插件有自己的经济系统，本模组**无法自动拦截**它们的扣款，但可以让它们主动上报：

```
/shop wallet log <玩家名> <金额> <事由>       金额负数 = 扣款，正数 = 入账（2 级权限，控制台也可执行）
```

* 上报后玩家账单里会出现类型为「**外部账目**」的记录，来源显示插件名，余额列显示「—」（因为它不动本模组余额）；
* 其它模组也可以直接调用服务端 API：`ShopManager.recordExternal(server, 玩家名, 金额, 事由, 来源)`；
* 做法示例：让那个插件在扣钱后，由控制台执行一次上面的命令即可。

### 11. JEI 联动（鼠标悬停物品 → 按 R / U 看配方）

装了 **JEI**（Just Enough Items）的客户端，在本模组界面里**把鼠标放到物品图标上**，直接按 JEI 的按键即可：

* **R（查看配方）** = 这件物品**是怎么来的**（JEI 里以「产物」身份查）——收购清单里不认识的物品，一按就知道出自哪个合成/掉落；
* **U（查看用途）** = 这件物品**能用来做什么**（JEI 里以「材料」身份查）。

支持的界面：**每日商店**（翻开后的卡牌/长条与收购清单）、**购物城**、**拍卖会**、**玩家摊位**、**摊位商品页**、**邮箱附件**、**货币兑换**、**管理员列表**。
按键认的是玩家自己的**按键绑定**（把 JEI 的键改成别的也照样生效）。

> 服务器**不需要**装 JEI，也不会因为没装而报错（本模组对 JEI 是纯软依赖，模组本身不打包 JEI 的任何代码）。

### 13. 出货箱配置（配置文件 `[shipping_bin]` 段）

出货箱的规则与容量都在服务端配置文件的 `[shipping_bin]` 段（改完 `/shop admin reload` 或重启生效）：

```toml
[shipping_bin]
    shippingEnabled = true                      # 是否启用这个模块
    shippingRules = ["minecraft:wheat=4", ...]   # 兑换规则（见下）
    shippingLevelSlots = ["9", "18", "27"]       # 每级容量：9 → 18 → 27（最高 27 格）
    shippingUpgradeCosts = ["2000", "10000"]     # 1→2 级、2→3 级的花费
    shippingDailyLimits = ["1000", "2500", "6000"]# 每级的每日结算上限（按下面刷新时间分界，0 = 不限）
    shippingSettleTick = 0                       # 结算时刻（0 = 早上 06:00）
    shippingResetTime = "00:00"                  # 每日额度刷新时刻（现实时间 HH:mm）
    shippingSettleWindow = 180                   # 结算窗口（刻，180 = 游戏内 9 秒）
```

**兑换规则写法**（每行一条，`//` 开头是注释）：

```toml
    "minecraft:wheat=4"            # 物品ID = 单价
    "#minecraft:logs=3"            # #标签 = 单价（标签里所有物品都按这个价收）
    "minecraft:*=2"                # 命名空间:* = 整个模组的物品都收
    "minecraft:diamond=100 x64"    # 单价 100，且这个物品每天最多结算 64 个
```

* **写错的规则不会生效**：解析失败会记下行号与原因，玩家打开出货箱时聊天栏红字提示，界面里也红字标出条数；
* **不在规则里的物品放不进去**（槽位直接拒绝），所以不用担心有人往里塞垃圾；
* **每日额度 + 两个时间**：「商店设置」→ 模块选**出货箱** → 点「**每日额度**」，弹窗一共 5 个框：
  按等级分档的**每级额度**（等级 1 / 2 / 3 各一行，0 = 不限），加上「**结算时间（游戏时间）**」与
  「**额度重置（现实时间）**」，保存立刻生效并写回配置文件。
  时间是 **HH:mm**，只填数字会自动补冒号（输入 `0600` → `06:00`）；格式不对弹窗里红字提示、
  点确认也不会生效（服务端还会再校验一次，写错会在聊天栏说明并拒绝保存）。
* **游戏内也能改规则**：「商店设置」页 → 「选择模块编辑」选**出货箱**，就能像编辑商品一样编辑兑换规则：
  左键改**单价 / 每日份数**、右键删除该条、「添加条目」放一件物品再填单价与每日份数即新增一条规则；
  **改完会立刻写回配置文件**（不用手动开 toml）。
* **每日上限**按等级算、**按「额度重置」时间刷新**（默认现实时间 0 点；设成 `04:00` 则凌晨 3 点还算前一天）；
  箱内价值超出今日剩余额度时只卖到额度用完，剩下的留在箱子里第二天继续（不会损失）；
* **结算时刻**：`shippingSettleTick = 0` 就是游戏时间早上 6:00（第二天早上结算"今天放进去的东西"），
  额度刷新时刻对应配置项 `shippingResetTime = "00:00"`。

## 四、配置文件

`config/module_shop-common.toml`（首次启动自动生成，注释为中文）：

```toml

                maxBalance = 9999999999   # 余额上限；写 0 = 不限（写 0 不会被纠正）`r`n transferCooldownTicks = 20   allowPlayerTransfer = true

                dailyRefreshCosts = ["200", "500"]        # 商店刷新价格表（长度=每天次数）
                buybackRefreshCosts = ["200", "500"]      # 收购刷新价格表（与商店独立）

                maxConcurrentAuctions = 6  auctionFeePercent = 5.0
                antiSnipe = true           antiSnipeSeconds = 60   antiSnipeExtensionSeconds = 0

```

* **付费刷新分开设置**：两串价格表**各自独立**，**列表长度 = 每天可刷新次数**。
  例：`dailyRefreshCosts = ["300"]`（商店每天 1 次、300 星币）、`buybackRefreshCosts = ["100","250","600"]`（收购每天 3 次）。
* `transactionHistorySize` 同时决定**账单保留条数**（10–200）。
* 旧默认值会自动迁移（货币名 金币→星币、邮箱上限 50→100、余额上限 999999999→9999999999），**服务端只换 jar 即可**。

## 五、界面层级与返回规则

| 层级 | 界面 | 返回 / ESC |
| --- | --- | --- |
| **一级** | 商店主界面（所有页签） | 关掉界面 |
| **二级** | 签到、交易选择、转账选择、玩家摊位列表、提醒音效设置、兑换码、拍卖出价、管理员发放、**账单** | 回一级 |
| **三级** | 某摊位商品页、数量/金额输入、交易界面、交易请求列表、日程编辑、日程奖励设置、日程奖励（物品发放式） | 回上一级；上一级没了就回一级 |

* 返回**不会来回循环**，也不会把你之前关掉的界面"弄回来"；
* 一级界面按 ESC 就是关闭界面（回到游戏）。

## 六、常见问题（FAQ）

**Q：玩家说看不到界面？**
A：客户端也必须装同一个 jar；按 K 或 `/shop` 打开。

**Q：东西买了/卖了却没进背包？**
A：背包满时会自动转**邮箱**（邮箱也满则掉落在脚下或金额直接到账），去邮箱领取即可。

**Q：邮件会越来越多吗？**
A：不会。同渠道且未领取的邮件会**自动合并成一封**；超过 100 封时会自动清理**最早的已读邮件**并提示。

**Q：能不能禁止同 IP 多开小号？**
A：**登录限制已按需求移除**（同一个 IP 可以正常多开）；但**同 IP 之间不能互相转账**这条经济规则仍然保留（管理员不受限）。如果需要一并去掉，告诉作者即可。

**Q：其它插件扣的钱能在账单里看到吗？**
A：能，但需要那个插件**主动上报**：让它扣完钱后由控制台执行
`/shop wallet log <玩家> <负数金额> <事由>`（或调用 `ShopManager.recordExternal`）。本模组无法自动拦截别的经济系统。

**Q：点击音效能换吗？**
A：可以。左下角**小齿轮** →「界面点击音效」一行，点一下换一款并**立刻试听**（共 10 款，选择存在客户端 `config/module_shop_click_sound.txt`）。

**Q：刷新商店/收购会互相影响吗？**
A：不会，两者**次数、价格、重抽范围**完全独立：商店刷新只重抽卡牌，收购刷新只重抽收购清单。

**Q：更新模组后要改配置吗？**
A：不用。服务端只替换 jar，玩法数据存在存档里，旧默认值自动迁移；只有你想调整价格表、权重之类的数值时才需要动配置文件。

**Q：能把左侧菜单列换个顺序、或者去掉/加回某个页面吗？**
A：可以（管理员）。「商店设置」→「编辑布局」→ 直接**拖动**页签换位（固定网格、松手自动吸附，其余页签平滑让位），松手即保存并**热同步给所有玩家**；
想删掉某个页面就把它**拖到右侧工具条**（变红 + 垃圾桶图标）松手后在二次确认里点「删除」；想加回来在下方**模块管理**里点「加入」或把该行**拖到左侧菜单**，
默认落在最下一格；左侧菜单**一屏 6 个**，放不下时把鼠标放在左侧列表上滚轮往下翻，最下面永远留一个空槽。编辑模式下点页签**不会切换界面**（模块功能停用），想切页先点「完成」退出编辑；想复原点「重置布局」。
