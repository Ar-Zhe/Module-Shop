## 2. 本轮新迁移的主页面

- [ ] 动画进行中连点不会重复发送；刷新按钮悬停显示花费与次数

- [ ] 月历翻页（年/月）正常；可补签日期有淡橙边框，点击能补签
- [ ] 今日签到按钮：可签时高亮，签完后变灰并显示状态
**购物城**
- [ ] 搜索框能输入中文（输入法候选窗位置正常），结果实时过滤
- [ ] 只看收藏、排序下拉、分类下拉都能用；**下拉菜单盖住物品图标**，菜单下的物品不弹提示
- [ ] 星标收藏能切换；最近购买视图与返回按钮正常；单击买一个、批量购买正常
**管理面板（管理员）**
- [ ] 模块下拉切换；列表左键编辑、右键删除；出货箱错误规则显示为红色
- [ ] 各模式下的按钮都能打开对应设置；带开关含义的按钮状态点正确
- [ ] 签到日程月历：点日期编辑、右键 × 清空

- [ ] **拍卖出价**：物品图标可悬停看详情；-10/-5/+5/+10 调整；拍卖已结束时确认变灰

- [ ] **摊位列表**：玩家头像、件数正常；平滑滚动；点击进入摊位；「管理我的摊位」回到商店

- [ ] **交易请求**：倒计时每秒递减，≤10 秒变红；接受 / 拒绝按钮有效
