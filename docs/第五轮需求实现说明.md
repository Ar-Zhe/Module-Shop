## 二、签到模块（第 7 条）

* **数据**：`data/SignInData.java`（按现实 `epochDay` 记日期、连续/最长天数、已签集合、里程已领集合、400 天自动裁剪）+ `ShopSavedData.signIns`（UUID → 数据）+ 全局设置。
* **界面** `client/screen/SignInScreen.java`（顶部栏「签到」按钮进入，走 Nav 返回栈）：
  * **里程进度条**：按连续天数填充，档位刻度与金额标注；**关闭累计签到时整条隐藏**；
  * **签到按钮**：未签可点、已签显示「今日已完成签到」并禁用；按现实 **0 点刷新**（`LocalDate.now()`）；
  * **日历**：`<` `<<` `>` `>>` 翻月/翻年、今日蓝框高亮、已签到格绿底、未来灰、可补签格子悬浮提示「点击补签（花费 X星币）」并可点击补签；
  * **活动日**：管理员设过的日期显示**金色描边**，悬浮显示「标题 · 公告 + 金额」；
  * **管理员**：底部「累计加成 / 自动签到 / 签到设置 / 编辑」四个小按钮；开启「编辑」后点进度条=改档位、点签到按钮=切自动签到、点日历格子=编辑活动日（右键取消）。

* **补签**：可补范围（默认 2 天）与花费（默认 100 星币）可配，扣款后补记录。

## 三、刷新参数与长条翻牌（第 8 条）

* **每日商店 / 每日收购各自一套参数**（存在世界数据里，管理员界面可改、无需改配置文件）：
  * `shopWeights` / `buybackWeights`：品质权重（传说,史诗,稀有,普通），默认 5,15,30,50；
  * `shopGuarantee` / `buybackGuarantee`：保底数量（稀有,史诗,传说），默认 0,0,0；
  * `shopSlotCount` / `buybackSlotCount`：牌数 / 条目上限，默认 6，可到 12。
* **生成逻辑**：每日商店按权重抽品质，抽完执行**保底补足**（不足时优先替换普通项、必要时追加，最多 12 张）；每日收购**先按权重抽品质、再在该品质里取条目**。
* **管理入口**：商店设置页新增「刷新参数」小按钮 → 弹窗回填当前模块的三项设置 → 确认后保存并**立刻按新参数重抽当天清单**。
* **牌数 > 6 的排版**：改为**每行 1 个横向长条**（品质色条 + 图标 + 名称自动省略 + 品质 + 价格 + 剩余，宽度自适应），保留原版翻牌动画与背面样式，**滚轮整行滚动** + 右侧滚动条；点击行为与音效不变。
* **列表滚动**：每日商店（>6 张）与每日收购（超过一屏）都支持滚轮整行滚动。
